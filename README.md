# ✈️ Airport Check-in and Baggage Management System

## 📌 Overview

Airport Check-in and Baggage Management System is a GUI-based desktop application developed using Java and JavaFX.  
This project simulates airport passenger check-in operations and baggage loading processes in a simple and user-friendly way.

The system stores passenger information such as:

- 🎫 Ticket Number
- 👤 Passenger Name
- 🧳 Baggage Weight

During the project, two important data structures were implemented:

- Stack
- Binary Search Tree (BST)

The Stack structure stores passenger baggage information according to the **LIFO (Last In First Out)** principle, representing real baggage loading and unloading operations in airplanes.

The Binary Search Tree (BST) stores passenger records in a sorted structure according to ticket numbers and enables fast searching operations.

Through the graphical user interface, users can:

- ➕ Add passengers
- 🔍 Search passenger information
- 🛄 Load baggage into cargo
- 📤 Unload the latest baggage
- 📋 Display all passenger records
